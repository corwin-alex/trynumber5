# Инструкция по развертыванию на Render.com

## Подключение к базе данных

Подключение к базе данных настроено с учетом требований Render.com:

### Локальная разработка
Используйте переменные окружения в файле `.env`:
```
DB_HOST=localhost
DB_PORT=5432
DB_NAME=your_database_name
DB_USER=your_username
DB_PASSWORD=your_password
```

### Развертывание на Render.com
Render.com автоматически предоставляет переменные окружения при привязке базы данных:
- `PGHOST` - хост базы данных
- `PGPORT` - порт (обычно 5432)
- `PGDATABASE` - имя базы данных
- `PGUSER` - пользователь
- `PGPASSWORD` - пароль

Код автоматически использует эти переменные, а также включает SSL-подключение для production-режима.

## Варианты развертывания

### Вариант 1: Использование render.yaml (рекомендуется)

Файл `render.yaml` уже создан и содержит конфигурацию для автоматического развертывания.

**Шаги:**
1. Создайте новый Web Service на Render.com
2. Подключите ваш GitHub репозиторий
3. Render автоматически обнаружит файл `render.yaml` и применит конфигурацию
4. База данных PostgreSQL будет создана автоматически

### Вариант 2: Ручная настройка

**Шаги:**

1. **Создайте базу данных PostgreSQL:**
   - В панели Render перейдите в "New" → "PostgreSQL"
   - Выберите бесплатный план (Free)
   - Запомните название базы данных

2. **Создайте Web Service:**
   - В панели Render перейдите в "New" → "Web Service"
   - Подключите ваш GitHub репозиторий
   - Настройте параметры:
     - **Name**: online-testing-app
     - **Region**: Frankfurt (или ближайший к вам)
     - **Branch**: main (или ваша основная ветка)
     - **Root Directory**: оставьте пустым
     - **Runtime**: Node
     - **Build Command**: `npm install && npm run build`
     - **Start Command**: `npm start`
     - **Instance Type**: Free

3. **Добавьте переменные окружения:**
   После создания базы данных, добавьте следующие переменные в настройки Web Service:
   - `NODE_ENV`: `production`
   - `PORT`: `5000`
   
   Затем привяжите базу данных:
   - В разделе "Databases" нажмите "Attach Database"
   - Выберите созданную базу данных PostgreSQL
   - Render автоматически добавит переменные `PGHOST`, `PGPORT`, `PGDATABASE`, `PGUSER`, `PGPASSWORD`

## Проверка подключения

После развертывания проверьте логи приложения:
- При запуске сервера вы увидите сообщение "Подключение к базе данных успешно"
- Затем будут созданы необходимые таблицы
- Если возникнут ошибки, они будут отображены в логах Render

## Структура базы данных

При первом запуске автоматически создаются следующие таблицы:
- `users` - пользователи (администраторы и студенты)
- `tests` - тесты
- `questions` - вопросы тестов
- `results` - результаты прохождения тестов

По умолчанию создается администратор:
- **Логин**: admin
- **Пароль**: admin123

## Безопасность

- SSL-подключение автоматически включается в production-режиме
- Пароли хешируются с помощью bcryptjs
- Используйте JWT для аутентификации
