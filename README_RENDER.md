# Развертывание на Render.com

## Автоматическое развертывание

Проект настроен для автоматического развертывания на Render.com с помощью файла `render.yaml`.

### Шаги:

1. **Загрузите код в GitHub/GitLab**
   ```bash
   git add .
   git commit -m "Add Render.com configuration"
   git push origin main
   ```

2. **Создайте сервис на Render.com**
   - Зайдите на [dashboard.render.com](https://dashboard.render.com/)
   - Нажмите "New +" → "Blueprint"
   - Подключите ваш репозиторий GitHub/GitLab
   - Render автоматически обнаружит файл `render.yaml` и применит настройки

3. **Проверьте логи**
   - После деплоя проверьте логи в панели управления Render
   - Убедитесь, что база данных подключена и таблицы созданы

## Ручная настройка (альтернатива)

Если вы хотите настроить сервис вручную:

1. Создайте новый Web Service на Render
2. Укажите параметры:
   - **Build Command**: `npm install && npm run build`
   - **Start Command**: `npm start`
   - **Environment Variables**:
     - `NODE_ENV`: `production`
     - `DATABASE_URL`: (автоматически добавится при создании базы данных Render)

3. Создайте PostgreSQL базу данных в разделе "Databases"
4. Добавьте переменную окружения `DATABASE_URL` из созданной базы данных

## Переменные окружения

Для работы приложения требуется:
- `DATABASE_URL` - строка подключения к PostgreSQL (автоматически предоставляется Render)
- `NODE_ENV` - режим работы (`production` для продакшена)
- `PORT` - порт сервера (автоматически устанавливается Render)

## Примечания

- При использовании `DATABASE_URL` подключение к базе данных происходит с SSL
- Функция создания базы данных отключена в режиме `DATABASE_URL`, так как база создается через панель Render
- Таблицы создаются автоматически при запуске сервера
